# Excalifont

The seven `excalifont-*.woff2` files (64768 bytes in all) are Excalifont Regular, version 1.000, copyright 2024 Excalidraw, based on Virgil by Your Own Font Foundry with modifications by Ján Filípek / DizajnDesign, licensed under the SIL Open Font License 1.1 (see `LICENSE.txt`). They are the unicode-range subsets the Excalidraw project ships, copied unchanged from <https://github.com/excalidraw/excalidraw> at commit `d732d4f3d50e6ac092ec6e86a4e04a40546a9395`, directory `packages/excalidraw/fonts/Excalifont/` (downloaded 2026-11-19; cut by Excalidraw with cn-font-split 5.2.2).

Each file was renamed from `Excalifont-Regular-<md5>.woff2` to `excalifont-<first 8 hex digits>.woff2`; `ranges.json` gives the unicode-range of each, taken from that directory's `index.ts`. `scripts/generate-font-table.mjs` reads it to register the family as `Mino Excalifont`.

Mino draws the Latin letters and digits of hand-drawn diagrams in it (T115).
