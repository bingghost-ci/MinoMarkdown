## 状态定义

| 状态 | 含义 |
| --- | --- |
| todo | 尚未开始 |
| inProgress | 正在实施 |
| codeComplete | 源码/配置/文档已实现，必要运行检查尚未完成 |
| automatedVerified | 该任务要求的自动化/构建检查有实际结果 |
| nativeVerified | 该任务要求的 macOS 原生操作/产物检查已完成 |
| accepted | 用户实际验收且已记录结论；不能由代理代签 |
| blocked | 该开发任务的必需条件不足，记录原因与解锁条件；不等同于客户端 Goal 状态 |

按任务定义选择目标层级，不要求纯自动化任务虚构原生操作。被新改动影响后，应重开相关验证；历史证据保留，不用覆盖失败记录来制造始终通过的历史。状态不是完成百分比，T29 完成也不自动把所有项改为 accepted。
