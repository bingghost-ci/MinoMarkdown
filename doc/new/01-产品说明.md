# Mino 产品说明

版本：1.0.0 · 日期：2026-11-20

本文说明 Mino 1.0.0 是什么、怎样工作，以及今后改动必须守住的约定。实现方式见[技术设计](02-技术设计.md)，各项功能验证到哪一步见[开发进度](04-开发进度.md)，面向使用者的介绍见 [README](../README.md)，各版本的变化见[发布日志](../CHANGELOG.md)，最初的需求见[原始需求](../Markdown编辑器.md)。

## 1. 定位与目标用户

Mino 是 Apple Silicon 上的 macOS 本地 Markdown 编辑器与阅读器。它以阅读为先：打开文档首先是读，像一本排好版的书；需要改时按 `⌘⇧R`，直接在排好版的页面上编辑。它也能阅读和编辑纯文本、代码与配置文件，并只读地阅读 PDF。

它面向用 Markdown 写笔记、书稿和技术文档，又想把它们当书来读的人，尤其是写中文的人。常见的用法有三种：

- 快速写一篇记录，粘贴截图，保存成普通的 `.md` 和旁边的图片。
- 维护一个已有的 Markdown 文件夹。
- 把文档用自己喜欢的版式读一遍，或导出成 HTML、PDF 给别人。

Mino 没有账户、云端和服务器。文档是磁盘上的普通文件，不依赖应用自己的数据库。

## 2. 产品原则

以下各条是今后改动必须守住的约定。

**默认离线。**

- 不开启 AI 时，应用不发出任何网络请求。字体、纸张纹理、图标、代码高亮和 PDF 渲染所需的资源都随应用安装。
- 界面（webview）没有任何网络和文件权限，CSP 不为任何功能放宽。唯一发网络请求的是 Rust 进程里的 AI 模块，并且只在用户开启 AI 并同意之后，只发往用户配置的地址。
- 没有统计和遥测。
- 文档里的远程图片不加载，预览、导出和 AI 的回答都是如此。导出的 HTML 不引用任何外部资源。

**文档不被悄悄改动。**

- 打开一个文件不会重写它。没有改动的文件不会被保存。
- 可视化编辑器无法原样写回的 Markdown 进入源码保护模式，保存时逐字节写回。
- 可视化模式保存时恢复文件原有的 front matter、BOM、换行风格和末尾换行。
- 文本文件按原编码写回。原编码写不出某些字符时先询问是否改存为 UTF-8，不同意就不写，绝不写出有损的文件。
- 磁盘上的文件被别的程序改过时，保存前提示冲突，不直接覆盖。
- 正式文件一律原子写入，并在旁边保留上一版的隐藏备份。写入失败时不显示“已保存”。

**外观只改呈现，不改文档。**

- 阅读风格、字体、排版、代码配色和图表画法都不向文档写入任何内容。图注、数字列右对齐、西文排版的语言标记只在显示时生成。
- 切换风格、字体或纹理强度只改 `<html>` 上的 `data-theme` 和 CSS 变量，不重建编辑器，不丢光标和撤销记录。
- 风格是数据（`src/features/reading/styles.ts`）。编辑器、预览、导出的 HTML、导出的 PDF 和打印的样式都由同一份数据生成，一种观感只在一处修改。

**任何搭配都要看得清。**

- 正文与纸面的对比度不低于 7:1，次要文字、链接和用强调色的标题不低于 4.5:1。纹理开到最强时仍须达标。
- 代码配色只换记号的颜色，不带底色，颜色按纸张的代码底色调到看得清。唯一的例外是用户自己选的颜色，原样使用。
- 图表的颜色由阅读风格推出，任何画法在 12 种风格下都可读。

**文件访问以授权为界。**

- 界面不向 Rust 传任意路径。能读写的只有用户通过系统对话框、拖入、Finder 打开所授权的文件和文件夹。符号链接和授权范围之外的路径被拒绝。
- 文档内容是不可信的：其中的脚本不执行，HTML 在预览、导出和打印前都经过净化。

**AI 由用户发起，不直接改文档。**

- AI 默认关闭。只有用户在面板或菜单里发起的操作才发送内容，没有后台分析。
- AI 的回答只有在用户选择“替换”或“插入”时才进入文档，并且可以撤销。

**其他约定。**

- 旧版本写下的设置在读取时迁移到现在的取值，不因为一个旧值把整份设置退回默认。
- 同一张图表每次画出来完全一样；纸张纹理、字体表和样例文件都由脚本生成，改脚本，不改产物。
- 只随附许可明确允许再分发的字体。商业字体不随附，用户自己安装后可在“本机”字体里选用。
- 没有验证过的事不写成结论：代码完成、自动化验证、实机验证和用户验收分别记录在[开发进度](04-开发进度.md)。

## 3. 功能说明

### 3.1 写作

**可视化编辑。** 编辑器基于 Milkdown/Crepe，支持段落、六级标题、加粗、斜体、删除线、有序和无序列表、任务列表、引用、代码块、行内代码、链接、图片、表格和分隔线。可以输入 Markdown 语法自动转换，也可以用工具栏、“格式”菜单和快捷键（见 [README](../README.md#常用快捷键)）。中文输入法组合输入期间不触发转换。

**源码模式。** 任何 Markdown 文档都可以切到源码编辑（“视图 › 切换源码 / 可视化模式”）。源码编辑器基于 CodeMirror，有行号和高亮。

**源码保护模式。** 打开时会检查文档能否经可视化编辑器原样写回。以下情况进入源码保护：显示净化后的预览，只能编辑源码，保存时原样写回。界面上会说明原因。

- 文件超过 2 MiB。
- 含扩展指令（`:::name`、`::name[...]` 等）或解析器不认识的语法。
- 公式的写法不是编辑器会写出的那种。行内 `$x$` 和独占行的 `$$` 块可以可视化编辑，其他写法进入源码保护。
- `latex` 代码块、单波浪线删除线等保存时会被改写的写法。
- 混用多种换行符，或 front matter 没有结束标记。

原始 HTML 和脚注留在可视化模式里按原样保留，编辑器加载后再核对一次这些片段是否原样。

**图片。** 可以粘贴截图、从对话框选择或拖入。新图片在保存前只存在于编辑器和草稿里；保存时写入文档旁边的 `assets/` 文件夹，Markdown 里只记录相对路径。单张图片上限 20 MiB 或 4000 万像素。删除图片节点不删除磁盘上的图片文件。

**编辑辅助。**

- 块操作：`⌥↑` / `⌥↓` 移动当前块，`⌘⇧D` 复制当前块，各算一步撤销。
- 智能粘贴：选中文字后粘贴一个安全的网址变成链接；粘贴制表符分隔的规则文本变成表格；代码块里始终按原文粘贴。
- 文字转换（只作用于选区，由用户触发）：大写、小写、单词首字母大写、中英文之间加空格、标点转全角或半角。
- 查找和替换（`⌘F`）：区分大小写、全词匹配、正则表达式；超过 2 MiB 的文档不能用正则。可视化模式一次最多高亮当前位置附近的 2000 处，总数照常显示。
- 状态栏显示字数。
- Mermaid 代码块画成图表，但不提供图形化编辑，源码仍是普通的 `mermaid` 代码块。

**不提供的语法。** 不新增 Markdown 语法：没有 `==高亮==`、上下标、下划线和文字颜色。

### 3.2 阅读与外观

**阅读模式。** 从 Finder、文件栏、拖入或“最近使用”打开的文档默认进入阅读模式；新建的文档、从草稿恢复的文档和有未保存修改的文档直接进入编辑。可在设置里改成“打开时直接编辑”。

- 阅读模式只读，只留纸面：隐藏工具栏、状态栏和各种编辑控件，顶部有一条细的阅读进度条。
- 空格和 `⇧空格` 翻页，`Home` / `End` 到首尾。大纲、查找、复制和缩放可用。
- 点击图片或图表，在查看器里放大看。
- 进入和退出阅读模式不重建编辑器，不影响撤销记录、未保存状态和草稿。
- Markdown 文档的滚动位置在本次运行内记住，切换标签回来时恢复。

**页面与悬浮按钮。** 正文默认显示为“页面”：灰色桌面上的一张圆角纸。也可以选“宽屏”铺满窗口。纸面右侧有一列悬浮圆形按钮：大纲、字体与风格、AI（开启后才出现）、日夜切换、阅读与编辑切换。

**阅读风格。** 共 12 种，7 种白天、5 种夜间。

| ID | 名称 | 明暗 | 纸张纹理 | 字体为“自动”时 |
| --- | --- | --- | --- | --- |
| `white` | 白 | 浅 | 无 | 思源黑体 |
| `mist` | 灰白 | 浅 | 无 | 思源宋体 |
| `paper` | 书页 | 浅 | 细压纹 | 思源宋体 |
| `xuan` | 宣纸 | 浅 | 长纤维和帘纹 | 霞鹜文楷 |
| `parchment` | 羊皮卷 | 浅 | 色斑和毛孔，四周做旧 | 思源宋体 |
| `kraft` | 牛皮纸 | 浅 | 横向纤维和杂点 | 霞鹜文楷 |
| `mint` | 豆沙绿 | 浅 | 无 | 思源黑体 |
| `charcoal` | 淡黑 | 深 | 无 | 思源黑体 |
| `dark` | 深灰 | 深 | 无 | 思源黑体 |
| `gray` | 中灰 | 深 | 无 | 思源黑体 |
| `slate` | 青灰 | 深 | 无 | 思源黑体 |
| `dusk` | 暖灰 | 深 | 无 | 思源宋体 |

- 新安装默认“跟随系统外观”：白天用“白”，夜间用“深灰”，两者都可以另选。
- 每种风格只有一个强调色，用于一、二级标题、链接和控件的选中状态。三级及以下标题用正文的墨色。正文不用纯黑或纯白。
- 窗口的界面（文件栏、标签栏、工具栏、状态栏、桌面）是灰色，向纸色靠拢 30%（`CHROME_TINT`）；界面上的文字保持中性。颜色主要在纸面和标题上。
- 没有系统标题栏：红绿灯在应用自己的顶行里，顶行空白处可以拖动窗口。窗口的浅色或深色外观跟随阅读风格，不跟随系统。
- 四种纸张的纹理是脚本生成的分层 PNG（`scripts/generate-paper-textures.mjs`）。“纸张纹理”强度 0–100，默认 60，0 为纯色纸面。纹理必须能认出纸种，又不能像污渍。
- 书页、宣纸、羊皮卷的引用带大引号装饰；宣纸、羊皮卷的一级标题居中，分隔线是花饰。
- 已移除的旧风格 ID（如 `light`、`eink`、`graphite`、`black`）在读取设置时迁移，对照表在 `styles.ts` 的 `legacyStyleIds` 和 `settings.rs` 里，两处必须一致。

**字体。** 中文、西文和代码字体分开选择，都可以选“自动”。

- 中文（7 款，全部随附）：思源宋体、霞鹜文楷、思源黑体、朱雀仿宋、寒蝉正楷、龙藏行书、马善政楷书。“自动”时用风格推荐的字体，见上表。
- 西文（5 款，全部随附）：Source Serif、Literata、EB Garamond、Inter、JetBrains Mono。“自动”时宋体和仿宋搭配 Source Serif，楷体和黑体用中文字体自带的西文。
- 代码：随附 JetBrains Mono（默认）、Fira Code（带连字）、Source Code Pro；另列出系统自带的 SF Mono、Menlo、Monaco。作用于代码块、行内代码、代码文件和源码编辑器。不按语言分别设置，连字不能单独开关。
- 本机字体：三类都可以选这台 Mac 上安装的任意字体，设置里保存为 `sys:<族名>`。应用只读取族名列表，不读取字体文件。族名在 TypeScript 和 Rust 两边都校验后才写进 CSS。
- 字号 13–22，`⌘=` / `⌘-` 调整，与设置里的字号是同一个值；`⌘0` 恢复为 15。
- 随附字体的来源和许可记录在 [`licenses/bundled-font-licenses.tsv`](licenses/bundled-font-licenses.tsv) 和 `src/assets/fonts/` 下各文件夹里。

**排版。**

- 行距：紧凑、舒适（默认）、宽松。段间距：紧凑、标准（默认）、宽松。
- 行宽：每行约 30、36（新安装默认）、42 个汉字，或不限。
- 对齐：左对齐（默认）或两端对齐。首行缩进默认关闭，只作用于正文段落。
- 表格：三线表（默认）或全框线。没有写对齐方式的纯数字列显示时右对齐。
- 西文排版：以西文为主的文档自动两端对齐、按音节断词，行高和行宽按西文换算。可以关闭。
- 图片：居中，不超过行宽，小图不放大。有纹理的四种风格给图片加衬边，其余用细边框。图片的标题或替代文本显示为图注（可关）。夜间风格下图片亮度降到 90%（可关）。

**代码配色。** 八个选项：随风格（默认）、素墨、GitHub、One、Solarized、Gruvbox、Tokyo Night、自定义。

- 每套配色有白天和夜间两半，随阅读风格的明暗取用。
- 记号分十四种：关键字、运算符、常量与内置名、数字、字符串、定义的名字、函数名、变量名、属性名、类型名、注释、修饰与标注、错误、标题。
- “自定义”逐种设置颜色，白天和夜间各存一套；没改过的记号按“随风格”显示；可以从一套现成配色开始。
- 作用于编辑器里的代码块、预览、代码文件的阅读视图、导出和打印。不能导入外部主题文件。

**缩放页面。** 阅读模式下在触控板上双指捏合，整页一起缩放，范围 60%–300%，接近 100% 时回到 100%。这是当前窗口的查看方式，不保存，也不改字号设置。编辑模式不缩放。

### 3.3 图表

Mermaid 代码块画成图表。Mermaid 自己只画朴素的图，其余由 Mino 在页面里完成（`src/features/diagrams/`）。画法、配色等只在设置里选，不写进文档。

**八种画法。** 每种是一种完整的画法，不是同一张图换颜色。

| ID | 名称 | 画法 |
| --- | --- | --- |
| `page` | 纸面（默认） | 节点染强调色，圆角，曲线 |
| `program` | 架构 | 浅色底板上的卡片，虚线分组框，带文字的连线用强调色；节点或分组加 `dark` 类成为深色核心块 |
| `hand` | 彩笔 | 一笔画成的墨线，底下是错开的水彩色块，每个节点一种颜色 |
| `pencil` | 铅笔 | 石墨灰细线描两遍，灰色排线当阴影，没有颜色 |
| `chalk` | 粉笔 | 黑板上的彩色粉笔线，不填色 |
| `scifi` | 科幻 | 深色屏幕和网格，切角面板，发光的描边，数据线走直线 |
| `ink` | 钢笔 | 方格纸上的墨线，方框描双线，实心箭头，不填色 |
| `color` | 彩色 | 每个节点一种颜色，连线取出发节点的颜色 |

- 彩笔、铅笔、粉笔、钢笔是手绘类。它们的线条由应用自己生成：边略微弓起并摆动，角不在尺规的位置上，圆不正圆。笔画由图形在图中的位置决定，所以每次重画都相同。
- 粉笔和科幻的底板在任何纸张上都是深色的。
- ID 沿用旧名（`hand`、`program`、`ink`），是为了让旧设置继续有效。

**画法之内可以改的。**

- 配色：随纸张（默认）、橙红、海蓝、松绿、葡萄紫、玫瑰、石墨，或自定义。自定义有五种颜色：强调色、节点底色、节点边框、连线、文字；没设的用画法自己的。
- 文字：随风格、正文字体、行书（龙藏体）、手写楷书（马善政楷书）、楷书（霞鹜文楷）、无衬线、等宽、科技（Oxanium），或本机字体。彩笔和粉笔默认手写楷书，铅笔和钢笔默认行书。
- 连线样式：随风格、实线、虚线、点线。文档里本来写成虚线的连线不变。
- 连线走向：随风格、曲线、折线、直线。
- 填充（只对手绘类）：随风格、水彩、排线、平涂、不填。
- 换一种画法时，连线样式、走向、填充和文字回到“随风格”，配色保留。这样每种画法先以它本来的样子出现。

**图标与批注。**

- 标签里写 `:名字:`（Lucide 图标的英文名）画成图标，例如 `A[:database: 保存到磁盘]`。这是 Mino 自己的写法，别的 Mermaid 工具会显示成原样的文字。图标随应用提供，不从网络取。
- 单独的图标用 Mermaid 的写法 `s@{ icon: "lucide:star" }`。
- 云形（`cloud`）、爆炸形（`bang`）和纯文字（`text`）节点画成批注，用虚线指向它说明的节点。
- 位置始终由 Mermaid 自动排版，不能把图标或批注拖到任意坐标。

**大小与查看。**

- 图表总是整张缩到给它的宽度之内，页面、导出的 HTML、导出的 PDF 和打印都一样，不出现横向滚动条，也不被裁切。
- 缩小后看不清的宽图，在阅读模式下点开，在查看器里按窗口大小显示，可以捏合缩放（10%–800%）和拖动。
- 切换风格或改任何一项，已经画出的图表原地重画。导出与屏幕用同一套选择。
- 画法在 WebKit 里核对，因为应用用的是 WebKit；Chrome 画 SVG 滤镜和细线的结果不同。

### 3.4 文件与窗口

**打开与新建。**

- 应用启动后是一篇空白的“未命名”文档，可以直接输入。不要求先建工作空间。
- 可以打开单个文件（`⌘O`）、文件夹（`⌘⇧O`），或把它们拖进窗口、拖到 Dock 图标上、用访达的“打开方式”交给 Mino。Mino 在文件关联里登记为备选程序，不抢占默认打开方式。
- 新建的文档总是 Markdown。文件栏里可以新建受支持的文本类型的文件，PDF 只能打开。
- “文件 › 打开最近使用”列出最近的文件。
- “恢复上次打开的文档”默认关闭；开启后，启动时重新打开主窗口上次的标签（最多 20 个）。

**标签与窗口。**

- 每个窗口有多个标签。打开和新建都保留已有的文档。
- 标签可以拖动排序，拖出窗口或用右键菜单“移到新窗口”成为独立窗口。`⌘⇧N` 新建窗口。
- 同一个文件不会被打开两次。

**文件栏。**

- 可以同时打开多个文件夹，每个是一段可折叠的目录，可以单独刷新和关闭。关闭一个文件夹只收回它自己的授权，已经从中打开的标签不受影响。
- 目录树只列受支持的文件，忽略隐藏项以及 `node_modules`、`target`、`dist`、`build`、`assets`、`venv`、`__pycache__`。
- 全文搜索覆盖所有已打开的文件夹里的文本类文件，没有持久索引，不做跨文件替换。
- 新建文件和文件夹、重命名、移到废纸篓。文件夹连同里面的内容一起重命名或移到废纸篓，其中已打开的文档随之关闭。“删除”一律是移到废纸篓，不提供永久删除。打开的根文件夹本身只能关闭。
- 拖动移动：把文件或文件夹拖到另一个文件夹上，可以跨已打开的几个根文件夹。同名时不覆盖；不能跨磁盘移动；文件夹不能拖进它自己。已打开的标签继续有效，之后保存到新位置。
- 移动 Markdown 文档时，它引用的 `assets/` 图片一起移到目标文件夹的 `assets/`。原文件夹里别的文档还在用的图片留下。目标里有同名但内容不同的图片时不移动并提示。
- 文件栏、大纲和 AI 栏都可以拖动边缘调整宽度，也可以隐藏。

**保存。**

- 平时手动保存（`⌘S`）。“自动保存”默认关闭；开启后按 15、30、60、120 或 300 秒的间隔把已有文件的修改写回磁盘，新建的文档仍需手动保存。
- 关闭窗口或退出时，已有文件的修改自动保存；未命名的文档询问保存、放弃或取消。保存失败或发现冲突时不关闭。
- 保存时比较磁盘文件的 SHA-256。文件被别的程序改过时进入冲突状态：可以查看差异、改用磁盘版本，或另存一份。没有改动的文档被外部修改时，提示重新加载。
- 每个文档旁边只留一份隐藏备份 `.mino-backup-<名字>-<哈希>.bak`，是刚被替换的那一版。
- 未保存的修改写入应用数据目录里的草稿：停止输入约 1.5 秒后写，最迟不超过 10 秒。意外退出后用“文件 › 恢复草稿…”找回，不在窗口里自动弹提示。

**右键菜单。** 正文、标签页、文件栏的文件和文件夹都有 macOS 原生的右键菜单，文字随界面语言，菜单项随文档类型和状态变化。阅读模式和只读视图里只留不改动文档的项。未保存过的新文档，其文件类菜单项置灰。

**界面语言。** 中文和英文，在设置里选。界面文字在 `src/app/i18n.ts`，原生菜单的文字在 `native_menu.rs`，两处分开维护。

### 3.5 其他格式

支持的扩展名只有一份清单，在 `src-tauri/src/file_kinds.rs`；它决定文件按哪一类打开。扩展名受支持但内容是二进制的文件不打开，提示格式不受支持。

| 类型 | 扩展名 | 能做什么 |
| --- | --- | --- |
| Markdown | `.md`、`.markdown` | 阅读、可视化和源码编辑、导出 |
| 纯文本 | `.txt`、`.text` | 阅读、编辑 |
| 代码与配置 | `.log`、JSON、YAML、TOML、XML、CSV、TSV、INI 和常见源码，共 50 种 | 带高亮阅读、编辑 |
| PDF | `.pdf` | 只读阅读 |

Word、EPUB、图片和压缩包不接受。

**文本编码。** 识别 UTF-8、UTF-16、GB18030（含 GBK）、Big5，其余由 `chardetng` 猜测。状态栏显示编码。保存时沿用原编码、BOM 和换行。

**纯文本。**

- 按纯文本排版：`#`、`*`、`_` 原样显示，不当作 Markdown。沿用阅读风格、字体、行距和西文排版。
- “第 X 章”“第 X 卷”“Chapter N”一类的标题生成大纲。
- 20 万字符以上先显示开头。上次读到的位置在重启后仍然记得。
- 用纯文本编辑器修改，同样有草稿、冲突检测和自动保存。“另存为”可以存成同类型的文件或 Markdown。

**代码与配置文件。**

- 带语法高亮和行号阅读，可以编辑保存，内容按原样写回，不做任何规范化。
- CSV 和 TSV 可以在表格和原文之间切换。
- HTML 文件只显示源码，不运行其中的脚本，不加载其中的资源。

**PDF。**

- 只读：连续滚动，缩放和适应宽度，文字可选可复制，页码跳转，文内查找，书签显示在大纲栏，记住上次读到的页。
- 页面可以按阅读风格着色，也可以显示 PDF 原本的颜色。
- 加密的文件输入密码后阅读，损坏的文件给出提示。
- 上限 200 MiB（其他类型 20 MiB）。不执行 PDF 里的脚本。外部链接与 Markdown 里的链接走同样的确认。
- 由随应用打包的 PDF.js 渲染，WebAssembly 关闭。文件的字节仍由 Rust 按授权分段读取。
- PDF 没有保存、导出和阅读模式切换，相应的菜单项置灰。

### 3.6 导出与打印

导出都从一份固定的快照生成，导出期间继续编辑不影响结果。导出不切换当前文件，“另存为”才切换。

| 操作 | 结果 |
| --- | --- |
| 导出 Markdown 与图片 | 文档和它的图片文件夹 |
| 导出仅正文 Markdown | 只有正文的 Markdown |
| 导出 HTML | 一个自包含的文件：样式、图片、纸张纹理和用到的字体都内嵌，不加载任何外部资源 |
| 导出 PDF | 直接写出 PDF 文件 |
| 打印（`⌘P`） | 系统打印面板 |

- **导出风格**对 HTML 和 PDF 生效：当前风格（默认）或简洁白底。
- **HTML 的字体。** 只内嵌文档实际用到的字符所在的字体分片，上限 6 MiB。超出时改用系统字体并提示；整体只有一个大文件的字体（如霞鹜文楷、寒蝉正楷）总会超出。本机字体不内嵌，只按族名引用。
- **导出 PDF。** 整页铺满导出风格的底色，包括页边距和夜间风格。文字可选中，字体内嵌，外部链接和文内跳转可点击。纸张纹理不导出，只有底色。没有页眉和页码。
- **打印。** “打印底色”默认“打印友好”（白底省墨，夜间风格改用深色墨水）；也可选“与屏幕一致”，这时只在打印区域内铺纸色，页边距仍是白的。这个设置只影响打印。
- **纸型和页边距**对导出 PDF 和打印都有效：A4（默认）或 Letter；窄、标准（默认）、宽。
- 源码保护的文档导出的是净化后的内容。
- 导出 PDF 和打印都由 Rust 把与导出 HTML 相同的页面放进一个关闭了 JavaScript 的离屏视图里完成。应用的 webview 里 `window.print()` 不起作用，不要依赖它。

### 3.7 AI 助手

AI 是可选功能，默认关闭。关闭时没有 AI 按钮和面板，不访问钥匙串，不发网络请求。

**开启。** 在设置的 AI 页开启，首次开启时说明“文档内容会发送到你配置的服务”并要求确认。

**服务与密钥。**

- 使用 OpenAI 兼容的流式对话接口。预置 DeepSeek 和 OpenAI，也可以自定义地址。地址必须是 `https://`；只有本机回环地址可以用 `http://`（本地模型和测试用）。
- 密钥由用户自备，各服务商分开保存在 macOS 钥匙串里，不写入设置文件、日志和错误信息，保存后不再显示。
- 模型可以自由填写，也可以从常用模型或从服务取回的列表里选，按服务商分别记住。取模型列表只发送密钥，不发送文档。
- 费用和服务条款是用户与服务商之间的事。

**能做什么。**

- 对全文：摘要、要点、关键概念、背景解读，或自由提问。推荐问题先由文档的标题在本地生成，也可以请 AI 生成。
- 对选中的文字：解释、翻译、改写、续写。结果可以替换选区或插在其后，算一次可撤销的编辑。阅读模式和只读视图里只有解释和翻译，不能插入。
- 回答可以复制、插入文档，或存为单独的文档，默认放在当前文档旁边。
- 纯文本和 PDF 也可以分析。PDF 取提取出的文字；没有文字层的扫描件会明确说明，不做 OCR。

**发送什么。** 提问时发送当前文档的标题和正文（或选中的文字及其前后一小段）、用户的问题和本次对话。不发送图片、其他文件、目录结构和本机路径。面板上常驻显示当前的服务商、模型和主机名。

**长文档。** 一次请求最多带约 3.2 万字符的正文。更长的文档分段摘要（最多 6 段）后再汇总，或截断；没带上的部分会告知用户。

**显示。** 回答按 Markdown 渲染，经过与预览相同的净化，不加载远程图片，不执行脚本，不触发文件操作。断网、没配置或关闭时，其余功能不受影响。

### 3.8 设置

“设置…”（`⌘,`）打开一个独立的系统窗口，全应用只有一个。它可以拖到任何显示器；改的每一项立即作用于所有文档窗口，不遮挡文档。设置窗口在前面时，`⌘W` 和 `Esc` 关闭它。窗口的位置和大小不记忆。浏览器开发预览里，以及设置窗口创建失败时，改用文档窗口里的对话框。

设置分七页：

| 页 | 内容 |
| --- | --- |
| 外观 | 界面语言、跟随系统外观及白天与夜间的风格、阅读风格、纸张纹理 |
| 代码配色 | 配色的选择和自定义颜色 |
| 图表 | 画法、配色、文字、连线样式、连线走向、填充，带实时预览；图标与批注的写法 |
| 排版 | 字号、字体、行距、行宽、段间距、对齐、首行缩进、表格、西文排版 |
| 阅读与导出 | 打开文件时进入阅读模式、显示图注、夜间降低图片亮度、导出风格、打印底色、纸型、页边距 |
| 工作区 | 正文显示模式（页面或宽屏）、显示文件栏、显示文件操作栏、自动保存、恢复上次打开的文档 |
| AI | 开关、服务商、接口地址、密钥、模型 |

纸面右侧“字体与风格”按钮弹出的面板是同一套控件的常用部分：字号、风格、纹理强度、字体和行距。

设置保存在应用数据目录的 `settings.json` 里。可选的取值在 TypeScript 和 `src-tauri/src/settings.rs` 里各列一份，由测试比较两处是否一致；新增一个取值时两处都要改。

## 4. 明确不做的事

- 账户、云同步、多人协作、插件。
- Windows、Linux 和 Intel Mac。
- 新的 Markdown 语法，或把风格、字体写进文档。
- 加载远程字体和远程图片；让 webview 获得网络权限或放宽 CSP。
- 随附商业字体；读取或复制本机的字体文件。
- 用户自定义阅读风格的编辑器；导入外部的代码配色主题。
- 图表的图形化编辑，或把节点、图标、批注拖到任意位置。
- Word、EPUB 等非纯文本格式；PDF 的批注、编辑、表单填写和 OCR；把 PDF 转成 Markdown。
- 导出 PDF 和打印的页眉与页码。
- 文件栏里的永久删除；跨磁盘移动。
- 全文件夹的引用自动修复：移动文档时只带走它自己引用的图片，不改写其他文档里指向它的链接。
- 图床、图片裁剪和自由布局。
- AI 方面：对话历史上传和云端同步、多文档知识库与向量索引、图片理解、联网搜索、让 AI 调用本机命令、后台自动分析。
- 统计和遥测。

## 5. 已知限制与未决事项

**发布状态。**

- 没有可下载的安装包，需要从源码构建。构建出的 `.app` 未签名、未公证；重新构建后 macOS 可能再次询问钥匙串授权。
- 项目自身的许可尚未确定。第三方依赖和随附字体的许可清单在 `doc/licenses/` 下。
- 只支持 Apple Silicon。安装包声明最低 macOS 12.0，但只在 macOS 27 上构建和使用过，更低的版本没有验证。

**验收状态。**

- 自动化测试通过，但它不覆盖原生行为。Finder 打开、中文输入法、导出 PDF 与打印的实际效果、性能都需要在真机上手动验证，步骤见[验收清单](03-验收清单.md)，目前尚未逐项做完。
- 每项功能验证到哪一步只记录在[开发进度](04-开发进度.md)，本文不重复。

**功能上的限制。**

- 单篇文档上限 20 MiB，PDF 200 MiB，单张图片 20 MiB 或 4000 万像素。
- 20 万字符以上的文档以阅读模式打开时，先显示开头，再换成整篇；这时不分析也不加载编辑器，文件按原样保存。开始编辑时才载入编辑器，内容多的长文档这一步仍然慢。
- 草稿按间隔写入，突然断电时最后几秒的输入可能来不及保存。
- 打印时纸色铺不到页边距，这是 WebKit 的限制；导出 PDF 没有这个问题。
- 导出的 PDF 不带纸张纹理。
- 导出 HTML 时，整体只有一个大文件的中文字体回退为系统字体。
- `:名字:` 图标是 Mino 自己的写法，在别的 Mermaid 工具里显示为文字。

**未决事项。**

- 默认字号在两处不一致：界面的默认值和 `⌘0` 恢复的值是 15（`src/app/textZoom.ts`），而 `settings.rs` 里新安装的默认值是 16。应当定下一个值并统一。
- 是否签名、公证并提供安装包。
- 项目采用什么许可。
