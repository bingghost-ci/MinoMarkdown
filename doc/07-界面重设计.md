# 界面重设计：文件夹与文档工作台

日期：2026-11-07。范围：桌面主窗口与编辑操作，不改变文档存储和原生权限模型。

## 审查

- 旧界面把打开文件夹放在顶部、侧栏和欢迎区，入口重复；顶栏和侧栏的操作层级不清。
- 四个目录操作按钮在窄侧栏中换行，挤占文件树空间。
- 格式工具栏同时展开文字按钮、表格操作和图片操作，编辑区被工具控件压缩。
- 当前文档名、未保存状态和正文之间距离过远；运行消息固定占用正文上方的一整行。
- 旧深色欢迎页的视觉重点放在空白而非下一步动作；颜色比最初版本克制，但仍缺乏文件与正文的主次关系。

## 方向

- 产品：面向本地文件夹的 Markdown 浏览与写作工具。
- 性格：清楚、安静、利落。
- 场景：文件管理器旁的一张写作桌。
- 重点：目录树的当前文件、正在编辑的文档。
- 识别细节：文档标签上的 `.md` 文件名与未保存圆点。

## 工作台

2026-11-07 用户复核后修订：移除应用内容区顶部品牌横幅；打开、新建、保存和导出集中在 macOS 菜单栏。文件操作栏默认隐藏，可从“视图”菜单或应用菜单“设置…”显示。文档区使用可拖动排序的多 Tab，右键提供关闭当前、右边和全部。

1. 菜单栏提供打开文件夹、打开文件、新建、保存、导出与打印；可选文件操作栏保留快捷按钮。
2. 左侧文件栏展示根目录和递归文件树；创建、重命名、废纸篓与关闭目录放在目录操作菜单。文件夹和 Markdown 文件使用同一线条图标族，当前文件用窄边线和浅色行标记。
   独立打开的 `.md`/`.markdown` 文档只显示在右侧 Tab，不要求创建或选择工作区；欢迎页并列提供单文件与文件夹入口，两者均支持从 Finder 拖到窗口任意位置。
3. 右侧多文档标签展示文件名和未保存圆点，可排序和按需关闭；标签右侧展示当前模式/保存状态。正文上方固定一行常用格式工具；其余格式、表格与图片细项放在更多菜单。
4. 运行消息移到底部状态栏，主题设置也在底部。冲突操作在正文上方显示；草稿恢复由文件菜单按需打开。
5. 明暗主题都使用中性底色。浅色的主动作与当前文件使用蓝色；深色主动作使用浅色对比。正文标题收敛到写作编辑器尺度。

2026-11-08 补充正文宽度：编辑工具栏右侧提供“居中 / 宽屏”两档。居中沿用 860px 的正文容器；宽屏占用可用编辑区，保留自适应左右留白。该偏好写入本机设置，并覆盖可视化与源码保护模式。

2026-11-08 多窗口修订：侧栏移除“最近使用”和“单独打开”重复列表，仅保留目录树；当前文档只在右侧 Tab 展示。拖动 Tab 到窗口边缘或用右键“移到新窗口”可拆成独立窗口，每个窗口的 Dock 条目显示选中 Tab 名称。最近文件由 Dock 图标右键菜单显示。新窗口和下次启动均从空白状态开始；草稿入口移至“文件 > 恢复草稿…”，不自动显示顶部恢复横幅。

2026-11-08 语言与 Dock 修订：Dock 图标右键增加“新建窗口”，位置在系统最近文件和窗口条目之后。设置页增加“界面语言”行，中文与 English 即时切换；界面、自定义原生菜单和 Dock 自定义项一起更新，系统提供的 Dock 控件仍遵循 macOS 系统语言。

2026-11-08 窗口与设置修订：浅色模式下的窗口缩放黑边按根容器、应用壳与编辑区三层背景和高度处理，正文高度不再依赖 `100vh` 的减法。设置改为“外观 / 编辑器 / 工作区”横向标签：五种主题、界面语言、正文字体、13–22 px 字号、三档行距、正文宽度、文件栏与文件操作栏开关。选项即时作用于编辑区并保存在本机设置；源码保护区保持等宽字形，但跟随字号与行距。主题用克制的中性色阶，缩略卡片显示配色，避免把设置页变成一长列下拉框。

表格插入改为小型尺寸选择器：工具栏“更多编辑工具 → 插入表格”和正文斜杠命令的 Table 均打开同一网格，鼠标拖选后松开创建，默认预览 3×3，最多可直接选 10 列、8 行。空段落输入反斜杠也会唤起斜杠命令；正文中已有文字时反斜杠仍作为普通转义字符。取消选择不会插入表格。

2026-11-08 启动编辑修订：移除居中的“打开 Markdown 文档”欢迎页及其样式。启动和新建窗口立即显示“未命名”Tab、格式工具栏与空白正文，并将焦点放入编辑器。关闭窗口或退出时，磁盘文档有修改就自动保存；未命名文档有修改就提示用户选择。已有文件冲突与保存失败时不关闭窗口。
