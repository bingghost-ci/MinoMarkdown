# 界面重设计：文件夹与文档工作台

日期：2026-11-07。范围：桌面主窗口与编辑操作，不改变文档存储和原生权限模型。

## 审查

- 旧界面把打开文件夹放在顶部、侧栏和欢迎区，入口重复；顶栏和侧栏的操作层级不清。
- 四个目录操作按钮在窄侧栏中换行，挤占文件树空间。
- 格式工具栏同时展开文字按钮、表格操作和图片操作，编辑区被工具控件压缩。
- 当前文档名、未保存状态和正文之间距离过远；运行消息固定占用正文上方的一整行。
- 旧深色欢迎页的视觉重点放在空白而非下一步动作；颜色比最初版本克制，但仍缺乏文件与正文的主次关系。

## 方向

- 产品：面向本地文件夹的 Markdown 浏览与写作工具。
- 性格：清楚、安静、利落。
- 场景：文件管理器旁的一张写作桌。
- 重点：目录树的当前文件、正在编辑的文档。
- 识别细节：文档标签上的 `.md` 文件名与未保存圆点。

## 工作台

2026-11-07 用户复核后修订：移除应用内容区顶部品牌横幅；打开、新建、保存和导出集中在 macOS 菜单栏。文件操作栏默认隐藏，可从“视图”菜单或应用菜单“设置…”显示。文档区使用可拖动排序的多 Tab，右键提供关闭当前、右边和全部；最近使用保存在应用数据目录，点击按路径直接重开，提供手动排序。

1. 菜单栏提供打开文件夹、打开文件、新建、保存、导出与打印；可选文件操作栏保留快捷按钮。
2. 左侧文件栏展示根目录、递归文件树和最近文件；创建、重命名、废纸篓与关闭目录放在目录操作菜单。文件夹和 Markdown 文件使用同一线条图标族，当前文件用窄边线和浅色行标记。
   独立打开的 `.md`/`.markdown` 文档显示在“单独打开”区域，不要求创建或选择工作区；欢迎页并列提供单文件与文件夹入口，两者均支持从 Finder 拖到窗口任意位置。
3. 右侧多文档标签展示文件名和未保存圆点，可排序和按需关闭；标签右侧展示当前模式/保存状态。正文上方固定一行常用格式工具；其余格式、表格与图片细项放在更多菜单。
4. 运行消息移到底部状态栏，主题设置也在底部。错误、恢复和冲突操作继续保留在正文上方，避免隐藏需要用户处理的状态。
5. 明暗主题都使用中性底色。浅色的主动作与当前文件使用蓝色；深色主动作使用浅色对比。正文标题收敛到写作编辑器尺度。
