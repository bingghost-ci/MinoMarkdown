# Mino 产品方案

版本：v0.1 · 日期：2026-11-06 · 输入：[原始需求](../Markdown编辑器.md)。

## 1. 产品定位

Mino 是以本地文件为中心的轻量桌面 Markdown 编辑器。用户打开文件或文件夹后直接编辑排版后的正文，可以输入简单 Markdown 语法，也可以点击工具栏；截图粘贴后能够随文档长期保存，并可输出 Markdown、HTML、PDF。

“接近飞书”落实为正文直接编辑、选区操作稳定、格式易发现、图片插入自然。首版不引入账户、云端服务或多人协作。

优先服务三种日常场景：单篇记录快速写作、已有 Markdown 目录维护、含截图的文档整理与分享。

## 2. 方案默认选择

以下是为形成可执行计划采用的默认建议。后续用户提出不同选择时，按影响范围调整，不把建议追认为原始需求。

| 编号 | 默认方案 | 原因与变更影响 |
| --- | --- | --- |
| D01 | 首版只交付 macOS；优先当前开发机架构 | 先把系统 WebView、中文输入、粘贴与打印验证完整；Windows/Linux 另立适配计划 |
| D02 | 自建桌面外壳，优先 Tauri 2 + Milkdown/Crepe | 文件和导出逻辑可独立维护；不直接改造完整开源应用。T06 前保留更换编辑器适配器的余地 |
| D03 | 顶部常驻工具栏，选中浮动栏可关闭 | 满足格式操作易发现；即使所锁 Crepe 版本无可用 TopBar，也由应用工具栏调用适配器 |
| D04 | 默认可视化，链接通过小面板修改 | 日常写作少暴露源码；无法可靠往返的文件进入明确标识的源码保护模式 |
| D05 | PDF 采用系统打印对话框中的“存储为 PDF” | 首版提供可验证的 macOS 路径；界面写“打印 / 保存为 PDF”，不承诺一键生成和可检测的保存完成 |
| D06 | 标准 Markdown + 常用 GFM；不编辑数学、Mermaid、脚注、任意 HTML | 保证首版可控；这些内容保留源码，不静默删除。围栏语言为 mermaid 时按普通代码块保存 |
| D07 | 图片放在文档旁 `assets/`，引用相对路径 | 文档可迁移，不依赖图床与应用数据库；另存和 MD 导出负责复制资源 |
| D08 | 编辑时手动保存；关闭窗口或退出时自动保存已绑定磁盘的修改 | 退出前遵守磁盘版本检查；保存失败时不关闭。未命名文档由用户决定保存、放弃或取消 |
| D09 | 多窗口、每窗口多文档 Tab | 打开和新建保留本窗口已有文档；Tab 可移到新窗口；逐个关闭未保存 Tab 时处理保存、放弃或取消 |

macOS 最低版本、支持的 CPU 架构和可发布签名方式在 T06/T28 的实际环境验证后记录，不在方案阶段编造兼容结论。

| 工具栏 | 格式状态、原选区应用、插入、历史、保存与导出 | 点击按钮丢失选区或把格式加到错误位置 |

### 3.2 首版配套建议

目录内新建文档/子目录、文件重命名、移到废纸篓、最近打开、macOS 文件关联/拖入文件、浅深主题与系统跟随、基础设置与键盘操作。它们是本方案纳入的配套能力，不作为已被用户单独确认的需求。

目录结构移动会影响其他文件的相对链接。首版不承诺全目录引用自动修复；有风险时解释影响并要求通过可审阅的“另存为”复制资源。重命名与废纸篓操作限定为明确选择的条目。

### 3.3 后续范围

编辑过程中的持续自动保存原文件、全文搜索/替换、大纲、图床、图片裁剪/自由布局、公式渲染、Mermaid 渲染、脚注可视化、Windows/Linux、同步、协作、AI、插件。首版 Goal 不包含这些功能。

## 4. 界面与交互

```text
┌──────────────────────────────────────────────────────────────┐
│ 打开 / 新建     项目记录.md · 未保存          保存   导出 ▾      │
├──────────────────────────────────────────────────────────────┤
│ 正文 ▾  B  I  删除线  代码  列表 ▾  链接  图片  表格  更多 ▾    │
├──────────────┬───────────────────────────────────────────────┤
│ 文件夹       │                                               │
│ ▾ notes      │          项目记录                             │
│   项目记录   │          在排版后的正文中直接输入……            │
│   操作说明   │                                               │
│ ▸ assets     │          [粘贴的截图]                          │
│              │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

这是信息结构示意，视觉细节以 T07 的原型为准。正文建议最大行宽约 760px，侧栏约 240px 可调；小窗口优先收起侧栏，工具栏次要项收进菜单。采用系统字体、清晰的中性色层次、标准图标和必要的边框，不用装饰性卡片挤占正文。

每个新窗口直接显示可编辑的“未命名”文档和格式工具栏，光标进入正文；不展示居中的打开提示。左侧文件栏只负责目录树，不重复列出已打开或最近使用的文档；当前打开的文件只显示在右侧 Tab。Dock 图标菜单保留系统最近打开的文件，各窗口条目以当前选中的 Tab 命名。状态区只显示用户能采取行动的信息，不展示 IPC、解析器或文件句柄等实现细节。

Dock 图标右键菜单增加“新建窗口”，与“文件 > 新建窗口”和 `⌘⇧N` 执行同一操作。应用“设置…”提供中文、英文界面选择，并持久化到本机设置；切换时更新窗口界面、自定义原生菜单和 Dock 自定义项，不修改文档内容或文件名。

工具栏必须有文字提示、键盘可达和清晰焦点；清除格式、插入链接等操作保留原始选区。源码保护模式有持续可见说明，并保留保存/另存/导出 MD 入口。

## 5. 关键用户流程

### 5.1 打开并编辑文件

打开文件 → 读取与兼容性检查 → 可视化编辑或源码保护模式 → 修改后显示未保存 → Cmd+S → 成功显示已保存。

打开未修改的文件不会因为编辑器初始化就自动重写。文件编码无法安全解码时保留原文件并说明；首版直接编辑 UTF-8（含 BOM），不自动转换未知编码。

### 5.2 新建、粘图与首次保存

新建未命名文档 → 粘贴截图并在光标处显示 → 自动保存可恢复草稿和临时附件 → Cmd+S 选择 `.md` 目标 → 先复制图片并生成最终引用 → 原子提交正文 → 更新会话。

用户取消保存时继续保留草稿。图片写入失败时正文不引用不存在的最终文件，界面显示可重试状态。删除图片节点不删除共享磁盘资源。

### 5.3 目录操作

打开文件夹 → 按需加载目录树 → 选择文档 → 在新 Tab 打开并保留已有文档。关闭窗口或退出时，已绑定磁盘且有修改的文档先按原版本校验并保存；未命名且有修改的文档询问保存、放弃或取消。保存失败、冲突或取消时保留窗口。文件夹中的非文档资源默认不铺满导航；忽略 `.git`、构建缓存及隐藏目录，允许后续设置调整。

拖动 Tab 调整本窗口顺序；拖出窗口边缘或使用 Tab 右键菜单，将它移到独立窗口。新窗口保持空白启动状态，不自动装载上次会话。需要恢复未保存草稿时使用“文件 > 恢复草稿…”，不在窗口顶部自动插入提示。

重命名正在编辑的文件时更新会话路径与监听；跨目录另存通过资源迁移流程完成。非空目录的递归重命名/删除暂不提供，避免首版引入隐含的大范围修改。

### 5.4 外部修改与关闭

干净文档被外部修改：提示可重新加载，保留阅读位置；已修改文档被外部修改：进入冲突状态，保留编辑快照，可查看磁盘版本、另存本地副本、重新加载。关闭未保存文档给出保存、放弃、取消，保存失败不能继续假装关闭成功。

### 5.5 导出

点击导出 → 固定当前编辑快照 → 等待该快照关联的图片处理完成 → 选择格式与位置 → 生成产物或进入打印对话框。

- MD：默认导出文档与资源目录；另存为会切换活动文件，导出不会。
- HTML：默认内嵌已解析的本地图片与样式，搬到另一目录依然能打开。
- PDF：准备只含正文的打印预览，打开系统对话框，由用户选择“存储为 PDF”。应用只提示“已打开打印对话框”；不能据此宣告 PDF 已保存。

导出期间继续编辑不会改变已捕获快照。无效本地图片需先修复，或由用户明确选择带占位符的输出；网络图片默认不下载，必须说明输出是否仍依赖网络。

| E02 | 兼容性检查与源码保护模式 | 防止未知 Markdown 被可视化往返删除 |
| E03 | 图片写入、迁移、异步插入统一管理 | 保证首次保存、撤销、另存与导出的资源一致 |
| E04 | 导出固定当前快照 | 保证未保存内容与并发编辑的输出可解释 |
| E05 | 文件访问、HTML 渲染和资源协议受限 | 文档内容不能获得桌面读写权限 |
| E06 | 依赖锁定、离线资源、许可证清单 | 形成可重复构建和可交接产物 |
| E07 | 轻量指标以固定环境和样本测量 | 不把框架宣传当成产品性能 |
| E08 | 源码、自动化、实机和用户验收分别记录 | 能明确判断开发完成到哪一层 |

## 8. 风险与退出策略

| 风险 | 早期验证 | 失败时的处理 |
| --- | --- | --- |
| WebView 中文输入/选区不稳定 | T03 使用系统中文输入法连续写作 | 优先调整编辑适配器；必要时定向验证 Vditor，不能带着吞字问题扩展目录功能 |
| Markdown 往返损失内容 | T02/T03 对比语义与原文保留 | 源码保护；若常见语法也失败，T06 不放行 |
| 图片粘贴或路径失效 | T04 真截图、中文路径、首次保存 | 调整原生剪贴板与资源服务；不能仅用网络图片演示代替 |
| PDF 字体与分页异常 | T05 真正打印并查看 PDF | 调整打印样式与平台桥接；若仍失败，记录并重新设计 PDF 路径 |
| Tauri 方案达不到产品要求 | T06 集中评审实测证据 | 提出明确替代方案及影响任务；未获新的路线决定前不自动迁移成 Electron 或改造 MarkText |
| 缺少对外签名身份 | T28 区分本地包和分发包 | 可交付本地验证产物；对外发布状态保留未完成 |

不在规划阶段承诺固定体积、内存、开发天数或跨平台效果。T06 冻结可测量目标，T27 对同环境复测并说明差异。
