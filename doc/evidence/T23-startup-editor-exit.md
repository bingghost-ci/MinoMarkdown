# T23 启动编辑器与退出保存

日期：2026-11-08。开发机 macOS Apple Silicon，使用临时新实例，保留用户原有进程。

## 代码变更

- 删除启动欢迎页渲染与样式，初始 Tab 名为“未命名”，编辑器创建后聚焦正文。
- 关闭窗口逐个检查 Tab：已绑定磁盘且有修改时直接调用现有保存路径；未命名且有修改时保留保存、放弃、取消选择。保存失败、磁盘冲突或用户取消均不执行窗口销毁。
- 应用菜单“退出”改为受控菜单动作；macOS 应用委托退出回调转交窗口执行相同离开流程。最后一个窗口完成处理后退出。

## 验证与边界

- 完整 `.app` 的新实例中，辅助功能树显示窗口标题“未命名”、`Markdown 编辑区域`、空白正文文本区和格式工具栏；不再显示居中的“打开 Markdown 文档”欢迎页。
- `npm run typecheck` 与 `cargo check --locked --offline` 通过。最终 arm64 打包及自动化结果见开发进度。
- 原生退出提醒的前 3 次尝试分别遇到旧进程复用、裸可执行文件缺少包资源、系统预定义退出入口绕过窗口处理。基于这些结果增加了受控菜单退出与应用委托回调；一次委托回调后的空窗口残留还暴露出 Tauri 退出事件拦截会误阻止最后窗口退出，已移除该拦截。按用户要求停止重复原生试验。未命名提醒、已绑定文件自动保存、Dock 系统退出和多窗口交互仍由用户集中验收。不能把静态与构建通过视为这些原生流程已通过。
