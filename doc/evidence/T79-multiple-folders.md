# T79 同时打开多个文件夹

日期：2026-11-11。层级：codeComplete，automatedVerified（授权逻辑有测试，界面只有离屏样张）；原生实机验证 PENDING，用户验收 PENDING。

## 实现

- 文件栏按打开顺序列出多个文件夹。每个文件夹的标题行可折叠，指针移上去时出现刷新和关闭按钮。
- 文件栏标题处的文件夹图标用于再打开一个文件夹；对话框、拖入、最近项目打开的文件夹都是追加，不再替换已有的。
- 同一个文件夹再次打开时不会重复列出：`register_workspace` 对同一路径返回已有授权。
- 搜索依次搜索全部文件夹并合并结果（合计最多 500 条）；打开多个文件夹时，结果后面标出所属文件夹。
- 关闭一个文件夹只释放它自己的授权和目录树状态；从中打开的文档各自持有授权，标签不受影响。目录操作菜单里的“关闭文件夹”在多个时变为“关闭全部文件夹”。
- 新建文档、新建目录作用于当前选中的目录；点文件夹标题会选中该文件夹的根目录。

## 自动化验证

Rust `several_folders_are_open_at_once_and_each_is_released_alone`：两个文件夹各自列出内容；同一文件夹第二次打开得到同一个令牌；释放第一个后，它的根令牌和子项令牌都返回 `OUT_OF_SCOPE`，第二个照常可用。原有的工作区测试全部通过。

前端的数组状态和搜索合并没有自动化测试。

## 2026-11-12 文件夹标题的右键菜单

用户要求在文件栏的文件夹标题上加右键菜单以关闭该目录。右键标题弹出菜单：刷新目录、关闭这个文件夹；打开多个文件夹时另有“关闭全部文件夹”。点击任意处、按 Esc、窗口失去焦点时菜单消失。动作复用原有的 `loadChildren` 与 `closeWorkspace`，授权逻辑没有变。离屏 WebKit 里用合成的 `contextmenu` 事件确认菜单出现、三项齐全、Esc 与点击能关闭；真实右键与关闭后的结果实机 PENDING。没有新增自动化测试。
