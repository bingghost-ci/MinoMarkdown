春日读书记

读书是一件安静的事。翻开一本排得好的书，纸色、字距、行宽都恰到好处，注意力自然落在文字上。Mino 想让 Markdown 也有这样的阅读体验：粗体用于强调，斜体用于书名与外文，inline code 用于命令，链接 用于出处。

书犹药也，善读之可以医愚。 —— 刘向

一、阅读的节奏

段落之间留出呼吸的空间，行宽保持在三十到四十个汉字之间，眼睛换行时不容易串行。English text mixes in naturally, with proper spacing between 中文 and Latin words.

  1. 选择合适的纸张风格
  2. 调整字体与行距
  3. 打开阅读模式，专心读完
  • 整理书单
  • 写一篇读后感
