在仓库根目录可用以下命令准备一次性副本；记下输出的临时路径。`ditto` 仅写入新建临时目录，后续所有破坏性操作均针对该副本：

```sh
sample_root="$(mktemp -d "${TMPDIR:-/tmp/}mino-acceptance.XXXXXX")"
ditto tests/fixtures/markdown "$sample_root/markdown"
python3 -c 'from pathlib import Path; import sys; Path(sys.argv[1]).write_bytes((b"a" * 1023 + b"\n") * 11264)' "$sample_root/markdown/large-source-11MiB.md"
shasum -a 256 src-tauri/target/release/bundle/macos/MinoMarkdown.app/Contents/MacOS/mino-markdown
shasum -a 256 tests/fixtures/markdown/F01-basic.md "$sample_root/markdown/F01-basic.md"
printf '样本副本：%s\n' "$sample_root"
```
