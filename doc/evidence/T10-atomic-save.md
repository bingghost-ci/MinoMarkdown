# T10 / G10 原子保存与磁盘版本

日期：2026-11-07（Asia/Bangkok）。自动化层级已验证；原生并发和异常环境留待集中实测。

## 实现

- 同文档写入在后端写锁内串行，使用预期 SHA-256 拒绝已检测到的外部变化。临时文件与目标同目录，完整写入并 `sync_all` 后提交；新目标以硬链接排他创建，已存在时不覆盖。
- 现有文件提交前再核对 hash，保留按内容 hash 命名的原版本硬链接备份。macOS 复制原 mode、ACL 和扩展属性到临时文件，再进行替换；目录项同步失败返回 `COMMIT_UNCERTAIN`，不假报完全成功。
- 前端会话按 revision 确认保存：保存 N 时的新输入 N+1 仍未保存。保存中第二次 Cmd+S 合并为随后一次保存请求；过期 generation 回调不更新新文档。

## 自动化证据

- Rust 6 项测试 PASS：写入、flush、替换前故障均保留原文字节；新建同名不覆盖；目标 hash 变化返回冲突；成功替换保留备份并保留 POSIX mode；伪造令牌/非主窗口拒绝。

- `./start.sh --build-only`：PASS，12.01 MiB 未签名 arm64 `.app`，主可执行文件 SHA-256 `f4d93a41047a5eff99bd6df7ad5188ed0107eb28928a83490a984cb92cc12a3c`。

## 限制

非协作进程在最终 hash 检查与替换之间仍可竞争；不能宣称消除所有并发覆盖。备份清理/恢复策略、系统文件协调和更完整的元数据/只读/磁盘满故障注入将在 T11/T12/T25 继续完善。写入成功但目录同步失败时磁盘可能已经改变，需在重试前重新读取版本。原生验收集中进行。

2026-11-07 补充加固：macOS 提交在同一已打开目录句柄上执行临时文件、备份、排他新建和替换；旧目标复查同时比对 hash 与文件身份。父目录在暂存后被换成外部目录链接的注入返回 `COMMIT_UNCERTAIN`，外部文件未改，原目录中的新文件可恢复。Rust 全量 35/35、arm64 构建通过；对非协作并发写入的最后竞态仍保留上述限制。
