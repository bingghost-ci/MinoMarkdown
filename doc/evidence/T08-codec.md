# T08 / G08 Markdown Codec 与源码保护

2026-11-07 体积边界对齐技术设计 §12：UTF-8 正文超过 5 MiB 时，在调用 Markdown 解析器前进入可编辑的源码保护模式，并保留原始文本；前端新增边界回归。类型检查、前端 59/59 PASS。超过 5 MiB 的原生输入与模式体验仍待集中实测。

日期：2026-11-07（Asia/Bangkok）。代码阶段完成；T03 原生编辑器往返仍留待用户集中实测。

## 实现

- 打开文件前运行 T02 的 UTF-8/GFM 兼容性分析。可视化模式只加载正文；front matter 原样留在 Codec 元信息中，保存时恢复原始 BOM、CRLF/LF 与末尾换行约定。
- HTML、脚注等不支持内容进入可编辑源码模式；界面持续展示保护原因。源码模式保留保存与“仅正文、不含附件”的 MD 导出，HTML/PDF 禁用。
- 模式切换由用户显式发起；从源码尝试可视化会重新执行兼容性检查。未修改的已有文件点击保存为 no-op，不因编辑器初始化而整理原文。尚有待保存图片时阻止切到源码，避免 blob 引用写入磁盘。

## 限制

源码保护模式的“导出源码 MD”明确不复制无法安全识别的附件；完整 MD 资源包在 T19 实现。复杂链接/图片路径、引用式语法在真实 Crepe 内的往返仍需集中原生测试。源码模式到可视化切换后的光标位置和撤销历史视为新的编辑历史边界，待体验复测。
